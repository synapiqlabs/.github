# SynapIQ Labs

We build and run software for growing businesses — web apps, mobile-friendly
tools and the backends behind them.

### What we've built

- **[Poultry Book](https://poultry.synapiqlabs.com)** — farm management for layer
  poultry farms: flocks, feed, eggs, attendance, inventory, sales and accounts.
  Works offline. In use at Smart Yield Agro.
- **[Yolk Story Billing](https://invoice.synapiqlabs.com)** — order-to-cash billing
  for a multi-channel egg distributor: challans, invoices and receipts.
- **[TaxDecider](https://taxdecider.synapiqlabs.com)** — old vs new tax regime
  comparison for Indian taxpayers, with PDF reports and an AI tax assistant.

### Stack we like
React · TypeScript · Go · PostgreSQL · Tailwind CSS
